# EmpresTI

Empréstimo de equipamentos internos. Negócio em `docs/PRD.md`, stack em `docs/adr/001-stack.md`, comandos e estado em `AGENTS.md`.

Variáveis de ambiente: copie `.env.example` para `.env.local` e preencha. A mesma lista vive no painel da Vercel (preview e production).
Os usuários nascem no `npm run db:seed`; o cadastro pela interface é fechado.
